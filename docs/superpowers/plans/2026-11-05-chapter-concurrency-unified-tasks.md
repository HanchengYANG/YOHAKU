# 章节并发与统一后台任务

## 已批准的约束

- 不同文章独立执行；来源提取、正文校对依次执行，之后分句和注音并行。注音内部先本地生成，再远端校对。
- HTTP 每提供方默认四个执行位、同文章最多两个；CLI 默认两个工作进程、同文章最多一个。旧会话保留 worker 0 目录与归属。
- 远端执行超时默认 180 秒，本地解析默认 120 秒，排队与依赖等待另计。429 退避释放执行位。请求独立取消，迟到结果校验版本和代次。
- 当前文章动态优先，同级文章轮转；连续三个前台任务后给后台一次机会。
- 来源、正文版本、阶段及范围共同决定执行锁；分句和读音写回分别合并到最新 HTML，保护人工内容与问答标记。
- 图片批次、文件导入草稿、分章、正文准备统一列在任务页。正文准备按一次请求的页或来源范围归档，后续访问建立新代次。
- 重试只执行失败节点，成功检查点继续复用。运行、排队和自动重试期间不能删除；失败任务软删除后普通心跳与重启不能重建。
- 删除任务保留文章、原件和预览。删除书籍则使关联执行失效，阻止迟到写回。

## 重复使用后的补充修复

- 后台调度先检查持久化的文本长度、注音范围和目标片段句界，避免在执行位占满时持续重建整章 HTML；读取复用仍严格限于当前同步调用。
- 隐藏阅读页停止 GET 轮询并中止在途读取，重新可见或联网时立即同步；旧请求不得覆盖当前文档或页码。已提交的后台准备继续执行。
- 准备失败时，校对入口优先定位诊断中对应的来源，保留已可阅读页面原有的编辑来源顺序。
- 注音仅对本地语义校验失败追加一次纠错，每批最多两次调用；分句在一次来源处理的所有缺口间共享一次纠错预算。保持原校验标准，网络失败或取消不触发语义纠错，所有结果验证成功前不提交修改；累计各次实际排队和执行耗时。
- 同一正文版本的成功注音范围完整覆盖旧失败范围时，任务视图将旧失败标记为已替代，调度门禁也使用相同的有效失败判断。原生失败记录与执行日志保留；不完整覆盖、旧版本及仍执行的子步骤仍维持原有保护。
- 首个来源的首个非空行与已确认文章标题精确对应时，冻结标题及原有空白，只让 AI 校对后续正文；正文危险删改检查独立进行。此保护不会猜测不匹配标题，也不会回写已处理的历史正文。

## 持续导入回归

- 原生文件输入取出 File 数组后清空，移除后可重新选择同一文件；使用中文选择按钮和已选列表，避免空的原生选择器提示与列表矛盾。上传期间锁定文件、移除、模式与粘贴操作，重新选择时清除旧错误。
- 文件暂存请求携带自定义标题，恢复草稿时无需重新输入；同页存储以外的服务端任务目录也能显示正确标题。
- EPUB 书籍导入跳过没有正文的图片封面等 spine，保留原文件与非空内容；全部为空时回滚空书和文章并保留草稿。
- 本地步骤结束时补记尚无最终权威计时的当前阶段，分别累计排队、执行和退避；不覆盖远端返回的准确计时，包括零毫秒。
- 未执行全书 PDF 分章的导入，按成功解析文件和确认导入计进度；已经启动全书提取的 PDF 保留真实页数。正文准备继续由独立任务表示。任务总时间称为“历时”，各步骤单独显示执行耗时。
- 正常排队、执行和自动重试期间不显示阅读页的重复重试按钮；失败或暂停仍保留明确恢复入口。

## 草稿离开、首屏恢复与执行用量

- 服务端已保存的导入草稿、OCR 进度和分章建议不会被标记为未保存。浏览器草稿缓存写入失败时，只有本地内容与服务端记录一致才解除保护；未上传文件和未保存的章节结构修改仍会提醒。
- 提供方确实返回的用量与实际请求设置显示在任务步骤的“执行来源”。仅保留允许的数值字段与推理参数信息；没有提供的数据不补零，也不记录正文、提示词或请求凭据。输出中的推理用量是输出总量的一部分。
- GUI 验收脚本可以按指定文章记录阅读响应是否有可读页、状态及正文哈希，不记录正文内容。该观察功能默认关闭，生产入口不加载。

## 首屏等待与人工保存后的资源回收

- 普通阅读页仍以约 1000 字为目标。PDF 书籍章节尚无已发布页时，允许先发布至少 300 字的稳定前缀：保留真实分句、连续的当前版本注音，并暂留可能跨页的尾句。第一屏发布后固定边界，后续沿用普通分页。
- PDF 分章核对可一次保留已纳入章节范围内的所有建议排除行，仍可逐项修改；章节勾选和范围外建议保持不变。确认排除后只剩空白的原页，其工作正文保存为空，首次 OCR 提取与原件保留。
- 人工保存事务将已完全失效的旧工作标为失效，提交后再取消其排队、执行或退避。仍有有效来源的共享工作和用于保存首次提取的步骤继续；保存被拒绝或回滚时不取消。迟到结果仍受版本保护。

第四次 GUI 重导 151 页，确认 18 章，一次保留了正文中的 20 处建议排除行。仅挂起第 15 章 PDF 第 115 页的校对，第 113–114 页经过真实 AI 处理形成 367 字可读首屏；从选章到首个可读响应约 2 分 03 秒，且第 115 页仍在运行。这是受控故障结果，不能将不同次真实 AI 耗时当作固定性能指标。新截图导入后，人工保存使受控旧校对立即结束并标为失效，后续真实分句与注音显示了修改结果。

## 删除事务与后台工作的原子性

删除书籍或文章时，数据库清理和关联导入的删除状态仍在原有事务内完成；不可回滚的请求取消延迟到事务结束后，并重新校验工作对象、来源范围或导入代次、删除标记。若最后的删除 SQL 失败，原事务恢复，正文处理和分章导入保留原请求继续完成；提交成功则释放执行位，迟到结果不能恢复已删除内容。各请求保持独立的取消错误与执行元数据。

真实后端与本地可控 HTTP 提供方的新测试覆盖文章／书籍删除的回滚、提交、单章与兄弟章节隔离、并发位释放和迟到返回；关联导入测试同时验证原 PDF 字节保留。浏览器控制连接仍不可用，本批没有新增实际 GUI 验收；验证记录见 `artifacts/gui-isolation/delete-rollback.md`。
