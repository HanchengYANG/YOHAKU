# UI／UX 改版第 5 步：任务、校对、AI 页与安装横幅

**设计文档：** `docs/superpowers/specs/2026-11-06-ui-ux-overhaul-design.md` §5，文案按 §1.1。
**节奏：** 用户不在时自动推进（见交接文档）。每个子任务只跑相关测试并单独提交、推送；最后跑一次 `npm run test:all`。

## 1. 任务页（§5.1）

- 列表页标题「任务」，主按钮「添加」，去掉说明段落和「任务类型」筛选。
- 标签「当前」「已归档」。「当前」分两组：「需要处理」（`taskAttention` 为 attention：失败、待核对、未完成草稿）在上，「进行中」在下；每组为空时不显示组标题；两组都空时只写「没有任务」。
- 每行：标题（任务自身标题，不带时间戳和编号）、一句状态、一个主操作：草稿「继续」、可重试的失败「重试」、已完成有结果「打开」，其余「查看」。不显示历时、执行细节、分句阶段说明。
- 详情页：保留标题、一句状态、错误（`ErrorNotice`）、主操作和删除；步骤列表收进折叠的「处理步骤」，每步只留名称和一句状态；去掉历时、执行耗时、说明段落。

测试：改 `unified-tasks.e2e.mjs` 中任务列表与详情的断言；新增「需要处理在前、进行中在后、行内重试」用例。

## 2. 安装横幅（§5.4）

- 桌面不再弹出横幅；账号菜单在可安装且未安装时显示「安装为 App」。
- 手机只提示一次，点「暂不」后不再出现（沿用现有的选择记录）。

测试：改 `pwa*.spec.mjs`；新增「桌面不显示横幅、菜单可安装」用例（用 `beforeinstallprompt` 替身）。

## 3. AI 页（§5.3）

- 账号菜单里「AI 设置」「角色配置」合并为「AI」；页面两个标签「连接」「角色」。
- 角色行：名称、一句用途（约 12 字）、提供方、模型名（不显示「名称 · id」）；高级设置默认折叠；去掉长说明。

测试：改 `api-base.e2e.mjs`、`stage2.e2e.mjs`（授权设置）、`stage1.spec.mjs`（账号菜单）中的入口与断言。

## 4. 校对页（§5.2）

- 左正文、右原件；原件栏约占一半；缩放与旋转改为原图上的图标按钮。
- 去掉说明段落和「注音来源：…」；处理状态合并为一个标签（如「待核对」）。
- 顶部只留：标题、来源选择、「完成核对」「返回阅读」。
- 补第 3 步删测试时留下的缺口中最重要的两项：来源编辑器里的输入法合成提交、撤销重做。

测试：改 `unified-sources.e2e.mjs` 中校对页断言；新增上述两个用例。

## 收尾

`npm run test:all`，更新 `ui-ux-handoff.md`，提交并推送。
