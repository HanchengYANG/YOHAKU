# UI／UX 改版第 3 步：阅读页

**设计文档：** `docs/superpowers/specs/2026-11-06-ui-ux-overhaul-design.md` §3，文案按 §1.1。
**节奏（用户已确认）：** 每个任务只跑相关测试；步骤结束跑一次 `npm run test:all`；视觉调整在内置浏览器里确认（1280、800、375 宽）。

## 现状

- 本机真实数据 110 篇文章中 109 篇走来源流程（`document.sourceWorkflow`，由 `PagedReader` 渲染），只有 1 篇旧文章走 `Reader` + `ReadingPreparation` 的分句路径。本步以 `PagedReader` 为主，旧路径只统一顶栏与文案。
- 阅读页现在从上到下：`BookNavigation`（返回书籍、第 N/M 篇、上一篇／下一篇、篇选择下拉、「导入阅读资料」）→ `PagedReader` 顶部分页条（上一页、第 N 页、下一页、「文章目录」）→ `Reader` 的元信息行（类型、字数、注音数、已保存）、标题、工具栏（注音、字号滑杆、校对正文、对话记录）→ 正文 → 页末分页条 → 页脚（导出、删除、转为书籍）。
- 对话面板：≥1024px 固定在右侧，`.reader-workspace.has-chat` 用网格为它留出位置；<1024px 为底部面板。
- `DocumentChat` 挂载时就拉取对话（关闭状态也会），可以向上报告问答组数。

## 任务

### 1. 阅读细栏 `ReadingBar`

新组件 `client/components/ReadingBar.jsx`，样式放在 `client/reader.css`（`main.jsx` 引入）。

- 左：有书时「← 《书名》」（`aria-label="返回书籍：书名"`），否则「← 书架」。侧栏收起时，最左侧加「展开书架」按钮。
- 中：文章标题 +「N / M 页 ▾」按钮（总页数未知时为「第 N 页 ▾」，单页旧文章不显示）。点开目录浮层：本书各篇（当前篇高亮，点击打开），当前篇各页（「第 N 页」，未准备好的加「· 准备中」），点击跳转。Esc 或点外部关闭。
- 右：注音开关（`aria-pressed`，文字「注音」）、字号（点开浮层里的滑杆，保留 `aria-label="阅读字号"`）、「校对」、「对话 N」（N 为问答组数，0 时只写「对话」）。
- `PagedReader` 渲染细栏，并把页码、页列表、跳页函数交给它；旧路径（`Reader`／`ReadingPreparation`）由 `App` 渲染同一个细栏，不带页码。
- 删除：`BookNavigation`（整个组件和 `App` 里的 `bookNavigation`、加载中的「打开所属书籍」提示）、`PagedReader` 顶部分页条和「文章目录」、`Reader` 的元信息行与工具栏、`sentence-actions` 里的「继续导入资料」、标题行（标题已在细栏）。旧文章的「重新分句」保留为页脚的文字按钮。
- `DocumentChat` 新增 `onGroupCount(count)`，`App` 存进状态传给细栏。

测试：更新 `unified-sources`、`stage1`、`reading-layout`、`reading-polish`、`chat-*` 中引用旧按钮名的地方；新增一个 `unified-sources` 用例：目录浮层列出本书各篇和当前篇各页并能跳页。

### 2. 翻页

- 正文底部：「← 上一页 · N / M · 下一页 →」，文字按钮，居中。
- 键盘 ← → 翻页（焦点在输入框、选区浮层或对话面板里时不响应）。
- 最后一页（`complete` 且没有下一页）底部显示「下一篇：<标题> →」，打开本书下一篇。
- 翻页后滚到正文顶部（现有行为）。

测试：`unified-sources` 新增：→ 键翻到第 2 页、← 返回；最后一页出现下一篇链接并能打开。

### 3. 布局

- 进入阅读页时侧栏自动收起，但不写入 `yohaku.sidebarCollapsed`；离开阅读页恢复用户自己的选择。阅读页里点「展开书架」以浮层打开侧栏（覆盖正文，点外部或选中条目后关闭）。
- 正文列定宽居中：`--reading-column: 760px`（含内边距），窄屏占满。
- 对话面板：窗口 ≥ 正文列 + 面板宽 + 边距（约 1200px）时并排；1024–1199px 时面板覆盖在正文上方，不再挤压正文；<1024px 保持底部面板。
- 手机：同一条细栏，标题截断，右侧按钮只留图标。

测试：`reading-layout.e2e.mjs` 改为断言：进入阅读页侧栏收起且不改变保存的选择、展开为浮层、离开后恢复；1100 宽打开对话不改变正文宽度。

### 4. 划词提问

- 浮层按钮改为胶囊：「翻译」「讲解语法」「提问…」（原「解释语法」「自定义问题」）；关闭按钮保留。
- 定位：选区上方空间够时放在上方，否则放在下方；水平方向不出视口。
- 修正：文章首个标题与第一句被一起高亮为同一句。先用真实数据复现（标题块与首段被分进同一个句子 id），再在显示层按块切分高亮矩形，或在分句时于块边界断句，择改动小者。

测试：更新 `chat-*`、`stage3`、`unified-sources` 中「解释语法」「自定义问题」的按钮名；新增标题高亮用例。

### 5. 准备未完成或失败时仍可阅读

- `PagedReader`：当前页未准备好但有 `provisionalPreview` 时（含失败状态），直接显示原文预览作为正文（无注音、无划词提问），上方一行提示：
  - 准备中：「注音还在准备」+ 细进度条；
  - 失败：「准备失败 · 重试」+ `ErrorNotice`（错误代码；AI 连接失效按 §1.2 例外显示）。
  - 没有预览时保留现在的准备卡片，但文案压缩为一行状态 + 进度条 + 「重试」「校对」。
- 去掉准备卡片里的来源标签、已运行时长、「已注音 x / y 字符」、「查看后台任务」以外的说明段落（任务链接保留）。
- 旧文章路径：`ReadingPreparation` 文案改为「正在准备」／「准备失败 · 重试」，错误用 `ErrorNotice`。

测试：更新 `unified-sources` 中准备、诊断、失败相关断言（保留行为，改文案）；新增：失败且有预览时显示原文与错误代码。

### 6. 错误横幅

- `App.jsx` 顶部 `error-banner` 改用 `ErrorNotice`（可关闭）。
- 书籍页重命名／排序失败后重新拉取也失败时，只在书籍页显示一条（交接遗留问题 6）：书籍页已显示错误时，不再写入顶部横幅。

测试：`stage1` 现有书籍页用例补一条断言：重新拉取失败时页面只有一个 `alert`。
