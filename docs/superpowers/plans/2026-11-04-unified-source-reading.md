# 统一导入、来源校对与阅读分页实施计划

**目标：**落实用户确认的三层阅读结构，使用不可变来源和带版本片段作为正文依据，新导入按阅读需求处理，兼容原有图片任务。

**架构：**来源文件与文章范围分离；来源片段保存正文、首次提取和修改历史；阅读页只保存片段范围。文章 HTML 为现有问答接口生成的缓存。当前页或来源请求持久化，离开后继续完成；在线当前页优先，随后两页预取。不同文章独立并行，提供方队列继续限制执行数量。

**技术：**现有 React、Express、Node SQLite，Python 本地文档解析及 NDLOCR，现有按提供方共享的 AI 队列。
