## 三张原图的人工质量核对

### 歌词截图

保留两行，抽查正文、14 组原有注音及对应关系未发现明确错误。「背中」整体对应「せなか」，「生まれた」只给「生」标「う」，送假名留在正文。空白间距有少量文本空格，可人工修改。

### 横排教材照片

四个逻辑段的正文与顺序、段落分隔和抽查读音基本可靠，未发现明确的印刷正文错字或漏句。首个「名字」保留特殊片假名「ミンツー」，标题和后文为「みょうじ」。30万、160万、300、各国排名及约1亿人的数字正确；160和300未被伪标原有假名。页码、页签、插图标签和绿色批注均未混入正文。

手写部分仍不可靠：右上批注识别成「被动」，放大原图更像「被告知」，仍需本人确认；底部部分可辨手写内容被笼统记为字迹不清。结果可用作待校对草稿，不能称为全图逐字准确。

### 竖排双页照片

初测正文串行顺序与47组原有注音基本正确，但把右页末句「最近、雨が多いですね」标成左页，还错误声称前一句跨页，并漏掉正文脚注星号。

补充通用规则（按真实页边界判归属、不把页内跨列当跨页、保留引用符号、不在非正文中补解释）后，单独真实复测：

- 第0–6块属于右页，第7–15块属于左页，实际分界正确。
- 错误跨页说明移除，先右页后左页、各页列从右向左的顺序一致。
- 「耳に残る*から」恢复星号；脚注不再添加原图没有的括号解释。
- 16块正文除补回星号外保持，47组原有读音与来源完全不变；逐组检查未见新增错读。
- 保留原图未完的「覚えてしまっ」，标记为不确定，没有按语义擅自补写。

余下边界：插图票面极小字仍需人工确认；非正文脚注的假名尚未结构化保留，不能宣称整图无损。

`npm run check`：89项 Node 测试通过并成功构建，包含网站会话、邀请、资料归属、外部身份唯一绑定、OAuth、图片存储、provider空预留、JSONL终态、验证脚本及真实网站进程重启。浏览器基线包含10项阅读回归和6项第二阶段流程，使用明确测试替身的模型部分不作为真实模型证明。

同时修复真实验证脚本漏传账号查询参数造成的误报，新增独立账号绑定预检回归，已用实际绑定运行成功。
