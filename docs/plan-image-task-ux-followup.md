# 图片任务体验改进计划

状态：首版已交付；2026-10-31 追加调整的实现与自动化验收已完成。用户已授权直接提交、推送并部署到树莓派。本文是独立后续计划，不覆盖已有计划。

## 2026-10-31 追加调整

以下最新要求优先于下方旧版交互描述，用户已授权修复后直接提交并部署：

- 禁止手动暂停任务，旧暂停及停止接口也不能绕过限制；正常草稿、排队、运行、待校对和归档任务不允许删除。
- 只有因错误暂停的未保存任务（`blocked`／`needs_attention`）可删除。删除时以服务端当前状态及版本为准，状态已恢复或已保存时拒绝，不自动重试删除。已删除请求保持幂等。
- 出错任务继续支持重试或人工处理；授权错误转人工时原子固定结果，避免后台恢复与手动编辑竞争。历史手动暂停的任务仍可继续处理，但不能直接删除。
- 修复文章最后一张图片不可移除的问题。删除沿用“图片及对应正文一起从草稿移除”的语义，支持撤销、重做和取消；保存后可成为无图片文章，旧图片来源及识别字段清空，其他文字、讨论与原图保留。
- 删除后若正文为空，仍需补入文字才能保存，不自动删除文章；任务结果也允许移除全部新图片后保存有效正文。
- 图片任务增加持久的整批分句阶段：所有图片识别与注音完成后合并正文统一分句，分句成功落盘后才进入 `ready`。分句失败只重试分句，不重做图片成功步骤；重启、授权恢复、旧尝试和删除保护均覆盖这个阶段。旧未保存的待校对任务只补分句，已保存任务不重新处理。
- 阅读页在完整分句前不显示正文、划词和问答，先展示无百分比的等待条；检测覆盖全文，不能仅凭存在一句就放行。分句失败继续隐藏阅读正文，提供重试、校对或返回书架；版本冲突读取最新正文后最多自动重试一次，避免无限循环。已分句任务结果直接沿用，不重复调用模型。

## 已确认需求（2026-10-30 首版）

### 1. 可区分的任务名称

- 任务名始终包含完整创建日期、时间（精确到秒）与稳定短编号。
- 加入书名、目标文章名及用户填写的标题，重复信息只出现一次。
- 都未填写时，显示首张图片原文件名与图片数量；空草稿仅显示时间和编号。
- 禁止使用“图片导入”“图片文章”“未命名任务”等通用名称作为任务名。
- 书名及目标文章名保存快照，准备草稿调整目标时更新，提交后固定。任务显示名与文章标题分开。
- 示例：`2026-10-30 21:35:08 · 《人间失格》 · 第一章 · #A83F21`；无标题示例：`2026-10-30 21:35:08 · IMG_2048.jpg · 3张 · #B29C46`。

### 2. 处理中禁止人工处理

排队、运行及等待授权恢复时隐藏人工校对和注音入口，必须先明确暂停。服务端也限制人工结果冻结、任务注音与旧图片注音接口，检查执行前和结果返回时的任务状态，防止旧页面和迟到结果绕过保护。暂停及处理结束后保留手动录入与注音兜底。

### 3. 首页与侧栏条件入口

共用当前账号未归档任务统计。有上传草稿、排队、运行、暂停、失败或待校对事项时显示；没有时隐藏。操作后立即刷新，跨设备及页面重新可见时继续同步。

### 4. 暂停、继续、重试与删除

- 主动暂停可继续，失败任务可只重试未完成步骤，已成功步骤和结果保留。
- 主动暂停在服务重启后保持暂停；意外中断继续按已有机制自动恢复。授权仍未恢复时给出明确原因。
- 兼容原有 `cancelled` 任务，恢复前验证图片版本。
- 删除须用户确认，移除任务及未保存结果的访问入口，保留已保存文章。服务端持久记录删除状态与幂等标识，迟到响应和重试不能使任务复活。
- 其他设备删除了正在上传的草稿时，本机文件继续保留；提供明确的另建草稿操作，用户选择后重新上传本机文件，不反复请求已删除的任务。
- 恢复后台会作废旧校对版本。若旧页面仍在人工编辑，保存时提示无法保存，完整保留输入供用户手动复制留存，不自动合并或覆盖。
- 暂停后尚未进入人工处理时锁定原图；固定人工结果后允许旋转并保存。此后恢复后台须通过全部原图版本预检，不能把不同版本图片与已成功识别结果拼接。

### 5. 保存后自动归档

识别完成只是待校对，不归档。用户手动保存或追加文章成功后，采用记录与文章保存一起提交，自动退出当前任务列表及入口统计。任务页提供“当前／已归档”，导入页保留归档入口，固定任务链接仍可访问。

## 实施约定（首版记录）

- `GET /api/image-tasks?scope=active|archived`：默认当前任务；任务、分页与状态统计使用一致的过滤条件，额外返回当前任务总数 `activeCount`。
- 任务响应补充可信的 `bookTitle`、`targetTitle` 快照；复用创建时间和任务 ID 生成展示名称，不改文章标题。
- 增加 `paused` 执行状态，`POST /api/image-tasks/:id/pause` 与 `/resume` 均检查任务版本；保留已有失败重试及旧停止接口的兼容行为。
- `DELETE /api/image-tasks/:id` 检查任务版本，使用删除标记，不移除文章或直接回收共享原图。
- 暂停、恢复和删除均使旧执行 token 失效；归档沿用文章采用记录，不另设执行状态。
