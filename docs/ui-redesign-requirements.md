# 余白（YOHAKU）UI 重设计 · 需求简档

> 本文件只约定**业务必不可少的元素**——缺了它们，业务就不成立。布局、组件形态、色彩、字体、图标、插画、动效、文案措辞等一律交给设计师自由发挥；凡未提及处，均为设计自由。

---

## 0. 产品与品牌

一句话：把书页照片、截图、歌词或文章收进个人书架，借助 AI 识别正文、补全读音，再对照原图校对、阅读和提问。

- 名字：**余白（YOHAKU）** · 副标语：**多语阅读与笔记**
- 文案原则：**克制、无装饰性废话**（去除“虚心涵泳”、“正在涵泳”、“読む、わかる、残す。”及无意义顶栏等矫情口号，界面仅保留功能性文案）
- 定位：**不限语种**。当前聚焦日语（振假名等），未来可扩展其他语言
- 用户：个人语言学习者；家庭服务器自托管；桌面 + 手机浏览器，可安装 PWA

---

## 1. 信息架构

**单工作台**：书架（导航）+ 主面板（内容），除登录门外无独立翻页体系。

```
工作台
├── 登录门：登录 / 凭邀请码注册 / 首次创建管理员账号
├── 书架（常驻）：材料聚合 + 搜索 + 快捷入口 + 用户菜单
└── 主面板
    ├── 首页（落地）
    ├── 图片导入
    ├── 编辑器 / 校对器
    ├── 阅读页
    ├── 书籍目录
    ├── AI 讨论
    ├── AI 设置（仅管理员）
    └──（规划）笔记本 / 复习 / 备份恢复
```

路由：`/` 首页；`#<id>` 单篇材料；`#book/<id>` 书籍目录 —— **深链接需保留**（可回刷、可收藏）。

## 2. 页面清单（仅业务必需）

### 登录门
- 三种形态：登录、凭邀请码注册、首次创建管理员账号
- 说明"AI 由管理员统一配置"

### 书架（常驻导航）
- 展示并可搜索全部材料（单篇 + 书籍）
- 导入文字、导入图片、新建书籍入口；管理员另有 AI 设置
- 用户菜单：登出；管理员可生成/复制邀请码
- 空书架 / 无搜索结果时的引导

### 首页（落地）
- 书架统计概览（书籍数、页数、独立材料数、总字数）
- 最近阅读列表（卡片直接进入对应书籍或单篇材料；不再重复放置边栏已有的导入/新建按钮，也不做容易把“打开书籍目录”和“最近阅读”混淆的双重卡片）
- **后续演进预留**：首页后续用于展示 AI 整理的复习内容、生词/句型记忆卡（Flashcards）等学习回顾模块

### 图片导入
- 支持选图 / 粘贴 / 拖放，一次一张（PNG/JPEG/WebP，≤12MB）
- 一键完成「上传 → 识别正文 → 生成注音」；中途失败保留已完成步骤、可重试
- 完成后进入校对

### 编辑器 / 校对器
- 编辑正文；为字词标注 / 修改 / 删除**整词读音**（阅读时只显示在汉字上方）
- 图片来源：**对照原图校对**（可旋转、缩放原图，查看识别记录；原图仅在此处显示供人工核对 OCR）
- 按词查找、批量或部分改音
- 归属：独立材料或加入某本书（可内联新建书）；保存后进入阅读

### 阅读页
- 展示正文 + 读音，可开关注音、调节字号
- 进入编辑与"围绕材料提问"（AI 讨论，桌面端右侧同屏伴读、移动端底部抽屉）
- 导出（Markdown / JSON）、删除
- 书籍内时可翻页 / 跳页 / 返回书籍

### 书籍目录
- 逐页追加（图片 / 文字）、排序、重命名、删除
- **每页独立保存自己的正文、读音、原图与讨论**（业务结构约束，不只是展示）

### AI 讨论
- 结合当前材料提问（词义 / 语法 / 句意），多轮追问，讨论可保存、重新打开
- 新讨论可选引用原文片段作为上下文

### AI 设置（仅管理员）
- 连接 / 切换 / 断开共享 AI 授权，查看授权状态与当前模型
- 普通成员只需看到一句"AI 由拥有者统一配置"

### 全局必备能力
- 每个列表与内容页有**加载中 / 空 / 出错**三种状态
- 未保存的修改在离开前需确认
- 操作的成败有即时反馈

## 3. 留白（明确交给设计师）

- 除上述"必需元素"外，一切皆自由：布局、导航形态、组件、色彩、字体、图标、插画、动效、文案语气。
- 规划预告（非本期实现）：阅读页将来会加入**朗读**与**旁注**能力，正文区与工具栏建议预留扩展余地，避免未来重构。
- 现状可作参考而非约束：现有为一套暖纸质感界面（深绿书架侧栏、米纸主区、赭橙点缀），对比基准与信息参考而已。

## 4. 后续业务与交互演进备忘（下一阶段实现）

### 伴读式 AI 讨论简化与整书连续对话
1. **移除手动「想讨论的原句」输入框与「选择已有讨论」下拉框**：
   - 在同屏伴读场景下，后端已自动携带当前页全文作为上下文，不再要求用户手动复制粘贴原句。
   - 原句引用改为由未来的**「在阅读正文中划词 → 点击『问 AI』」**触发，选中片段以轻量引用标签（Chip / 引用块）自动带入提问区上方。
2. **一本书共享一个连续对话（独立材料每篇一个对话）**：
   - 取消「每页底下建立多个讨论线程」的碎片化模式；同一本书跨页阅读时共享同一个连续对话流（复用同一个 Codex `threadId`）。
   - **跨页上下文策略**：用户在第 $N$ 页发起提问时，后端在延续该书对话历史的同时，自动将**当前所在页（第 $N$ 页）的标题与原文**注入本轮提问上下文，既保持整书人物/语境连贯，又无需一次性塞入整本书全部书页原文。
