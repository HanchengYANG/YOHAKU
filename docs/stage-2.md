# 第二阶段：订阅授权、图片草稿与 AI 讨论

更新日期：2026-10-28。第一阶段已获用户验收。本阶段先接通官方订阅授权，再用真实推理验收图片与多轮对话。

## 当前入口

打开 <http://127.0.0.1:4317>，先创建站内账号或登录。首次创建的账号接收旧本机资料；朋友需要邀请码注册，书架与授权相互独立。

1. AI 设置：初始用户可点击「绑定刚才的 ChatGPT 授权」认领此前已完成的授权；其他用户点击 **Continue with ChatGPT**，在官方页面授权自己的订阅。不会借用别人的连接。
2. 图片导入：选择 PNG、JPEG 或 WebP（最大 12 MB），识别完成后先进入校对草稿；原图、阅读预览可切换，识别疑点、页码与手写批注单独展示。点击「保存并阅读」后才写入书架。
3. AI 讨论：在已保存材料中点击「问 AI」，可填原文片段或围绕全文提问、继续追问，讨论可重新打开。选区附近快捷提问和对话转旁注属于第三阶段。

没有取得授权时会如实提示，不返回演示识别或伪造答案。授权成功也只表示订阅权限已批准，仍需真实推理完成来验证模型访问。

## 认证与数据

- 使用官方 SIWC 动态注册、PKCE、state、nonce、ID token 签名／issuer／audience／时效与授权 scope 校验。
- 应用自己获取的凭据位于 `data/users/<userId>/providers/openai/`，目录 0700、文件 0600、原子写入；不读取或复制现有 Codex 登录文件，不创建 API key，不自动切换到额外收费 API。
- Codex app-server 用 stdio 连接；模型目录仅用于选取支持图片的模型，不能作为账户推理权限证明。只有最终 `turn.status=completed` 且完整最终文本可用才算成功。
- 网站账号、资料、授权目录和聊天线程均隔离。OpenAI 的同一身份不能同时绑定到不同网站账号；未登录请求被拒绝，朋友未授权时不会触发管理员的模型调用。当前服务仍只绑定本机地址。
- 原图在 `data/images/`；识别草稿、原图引用、注音来源、阅读顺序与非正文记录持久保存。原文／读音均可手动修改。
- 数据库采用增加字段的迁移方式，原文保持。迁移前备份位于 `data/backups/before-stage-2.sqlite` 和 `before-accounts.sqlite`，不进入 Git。
- Provider 接口独立于图片／讨论业务。当前仅 OpenAI 启用；Claude、API Base 是禁用的空预留，不会联网或创建密钥。详见 [架构说明](architecture.md)。

## 开发验证与真实验收的区别

`npm test` 包含真实 JWT 签名、错误认证、并发刷新、原图解码和持久保存、接口与数据库、Codex JSONL 生命周期等检查。其中模型响应和 OAuth 服务器测试替身均仅出现在测试文件里，不能证明真实 OCR 或订阅接通。

```bash
npm run check
npm run test:browser
npm run test:browser:ai
```

第二阶段浏览器测试使用独立的 `artifacts/ai-e2e-data/` 和明确标注的测试替身，仍走真实图片处理、HTTP API、SQLite 与 UI。不会把替身接入生产应用。

## 真实能力验证（需要用户先授权）

```bash
npm run verify:ai
# 在全新 CLI 进程中恢复同一个线程：
npm run verify:ai -- --resume
```

脚本直接调用当前网站用户绑定的 provider，默认选择初始用户；可用 `--user=用户名` 明确选择。为避免与网站并发刷新旋转凭据，运行时需要先停止本机服务。未建站内账号或未绑定授权时退出，不发起推理。绑定完成后才会：

- 直接测试中文解释与连续追问，并以随机讨论代号验证上下文，不在书架创建或删除材料。
- 分别真实识别三张原始测试图和一张新生成的日语文字图，检查关键正文、原有特殊读音、手写批注分离与双页顺序。
- 把真实结果保存到 `artifacts/ai-verification/<userId>/`，用新的 CLI 进程恢复同一线程并验证讨论代号；运行结束后重开网站服务。

自动核对点只证明被检查的部分；照片正文、细小注音和语音自然程度不能靠这些核对点推断。真实 OCR 完成后还需逐图对照，发现问题应记录，不能硬编码修正固定样本。

## 本次实测与剩余验收

用户已完成站内账号与授权绑定，真实中文问答、多轮随机代号、新 CLI 续聊、三张原图及一张新图的模型输入均已实测。本人登录的真实网页也完成文字导入、问答、追问、刷新重开及网站服务重启后的续聊。

逐图核对发现并记录手写批注限制；竖排初测的页归属和脚注符号问题在补充通用提示后的单独复测中修正。不能把自动核对点通过视为整图无损。详见 [本机实测记录](validation-2026-10-28.md)。

Chrome 扩展未允许自动选择本地文件，网页图片流程仍需用户手动选图验收。手机实机、长期运行、真实额度耗尽和语音听评尚未验证。

语音、选区快捷提问、旁注、笔记本、复习与树莓派部署不在本次已完成项中。
