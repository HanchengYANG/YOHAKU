# 子计划：安装提示、AI 对话与正文交互改进

记录日期：2026-10-30。

状态：已完成实现与本机验收（2026-10-30）。采用用户确认的 A「双色轻高亮」及第二版交互；后续图片工作流改进也已完成，用户已授权提交与部署。

本子计划补充 [主计划](./plan.md)；涉及本轮界面行为时，以本子计划为准。

## 已确认的交互

- 点击正文问答高亮后，只显示与该处关联的记录，并提供“查看全部对话”。关联记录可能穿插在其他片段的问答之间，必须根据问答组关联提取，保留原始消息顺序。
- PWA 提示选择使用 Cookie 记忆，记忆周期与网站登录状态同步，不采用独立的一年／30 天／7 天提醒周期。这里指网站登录会话，不是 AI 提供方授权。
- 移除对话面板中的“翻译此片段”“解释此片段语法”；正文划词菜单中的“翻译”“解释语法”“自定义问题”继续保留。
- 阅读和编辑界面采用同一套克制的视觉规则：悬停句子淡淡突出，已提问片段持续轻量高亮。高亮直接出现在实际正文中。
- 采用浅暖灰整句悬停、浅绿常驻问答高亮，约 120 毫秒背景渐变；高亮完整包住上方振假名，系统要求减少动画时关闭渐变。
- 桌面关联记录固定在右侧，手机采用底部覆盖式抽屉；消息独立滚动，打开、筛选、关闭记录保留正文位置，不把记录排在长正文下方。桌面预留记录区宽度，避免开关时正文重新换行。

## 1. PWA 安装提示记住选择

- [x] 使用 Cookie 保存“暂不”、iOS 安装说明“知道了”、原生安装弹窗接受／拒绝等明确选择，覆盖刷新、重开页面与重复 `beforeinstallprompt` 事件。
- [x] 在同一次有效登录会话内，已作选择就不再主动提示。到期时间对齐该登录会话的实际结束时间，不在每次刷新或选择时重新延长一个完整周期；退出、登录失效或切换账号后重新评估。已安装或独立窗口运行时始终隐藏安装提示。
- [x] 当前登录有效期由服务端定义为 7 天；实现时复用会话期限，避免前端另写一个脱节的固定值。登录 Cookie 保持 HttpOnly，不向前端暴露会话令牌。
- [x] 登录状态尚在加载时避免先闪出提示；登录前后的选择平滑衔接，避免刚登录又提示一次。访客的选择至少在当前访客会话内有效。
- [x] 兼容既有 iOS 说明已关闭的记录；Cookie 不可用时至少维持当前页面内的选择。安装提示与证书下载／信任指引分别处理，证书入口仍可访问。

实施前依据：Android 的“暂不”和证书说明关闭仅保存于组件状态；iOS 说明使用独立的 localStorage 标记，尚未与登录状态统一。

## 2. AI 对话精简与 Markdown 渲染

- [x] 删除对话面板内每个活动问答组下重复的“翻译此片段”“解释此片段语法”按钮。保留引用、输入框和正常追问能力。
- [x] AI 回复渲染 Markdown，覆盖段落、标题、强调、列表、引用、链接、行内代码、代码块及表格；旧回复与新回复一致显示，用户问题仍按原始文本显示。
- [x] 使用受维护的 Markdown 渲染方案；禁用回复中的原始 HTML，限制链接协议，避免将模型文本直接当 HTML 注入。保留现有回答来源链接与时间。
- [x] 调整现有 `white-space: pre-wrap` 等样式，避免 Markdown 段落／列表额外空行、手机宽度溢出；较宽的表格和代码块在各自区域内滚动。

实施前依据：`DocumentChat` 直接输出 `message.content`，尚无 Markdown 渲染。

## 3. 阅读模式的句子与问答高亮

- [x] 鼠标悬停时，淡淡突出该位置所属的整句，移出后恢复。根据已保存的句子 ID 判断，不按标点临时切句；同一句跨来源节点、问答标记或振假名时整体响应。
- [x] 已提问片段使用低饱和度浅色背景或同等轻量标识，避免抢占阅读注意力。常驻问答标记与临时整句悬停效果可叠加，原文和注音保持清晰。
- [x] 点击问答高亮，打开该位置关联记录视图；只读取历史，不自动发起 AI 请求。普通拖动划词仍正常工作，选中文字后不误触历史入口。
- [x] 关联单个组时显示其全部问答与追问；同一位置关联多个组时显示这些组的相关消息，并明确当前追问属于哪个组。筛选范围与追问目标分别维护，切换追问目标不丢失其他关联记录。
- [x] 关联视图与全部对话均按服务端保存的消息原顺序呈现，保持问答配对。不要再先按组集中排列、打乱穿插顺序；时间相同时保留原有顺序。
- [x] 打开关联记录时定位到该处最近的一轮问答，允许向上查看更早记录；“查看全部对话”恢复完整时间线。完整视图仍能查看游离问答和没有组 ID 的旧记录。
- [x] 保留两种再次提问方式：在关联记录中继续追问选定组；重新划选该处后发起新问题并建立新组。重叠片段允许关联多个组，不按相同词串误关联到其他位置。
- [x] 桌面支持悬停与点击，触屏设备直接点击标记查看历史；标记提供键盘访问方式，不影响文字选择。

穿插示例：完整对话为 `A 首问 → B 首问 → A 追问`；点击仅关联 A 的片段，显示 `A 首问 → A 追问`；点击同时关联 A、B 的片段或查看全部时，保持原始穿插顺序。追问 A 后，新的问题与回答继续归入 A。

实施前依据：底层已保存问答组 ID、正文关联和原始消息序列；界面目前只设置活动组，仍展示全部组，并按组重新排列消息。

## 4. 正文编辑区简化与高亮

- [x] 放大真正用于输入的正文编辑区，让其利用可用视口高度与宽度；在有来源图时保留实用的原图对照布局，手机上保证正文有足够编辑空间。
- [x] 删除“正文中的句子、来源与问答标记”折叠区，移除重复的一份正文显示。把有用的句子、问答高亮和点击入口放回实际编辑面。
- [x] 实际正文编辑面支持与阅读模式一致的整句悬停、已提问片段轻量高亮及关联记录查看。不能只在旁边预览或原折叠区中实现。
- [x] 点击问答标记查看记录与点击文字放置光标、拖动选择、双击选词可区分，不抢走正常编辑操作；再次提问入口与阅读侧的关联规则一致。
- [x] 保留注音添加／校正、批量注音、来源图片定位、句界处插入归属、重新分句、游离提示、保存／取消及撤销／重做。
- [x] 保存后重开，句子 ID、问答组标记、来源和振假名正确；普通修改不自动重新分句。删除会话后，编辑器撤销／重做不能恢复已失效的问答标记。

实现约束：当前输入面是原生 `textarea`，不能直接为局部文字添加 `span`／`mark`。执行时先验证同步高亮装饰层能否在换行、滚动、缩放和字体变化后准确对齐；若无法可靠满足交互，再采用受控可编辑正文方案。无论采用何种实现，保持统一的正文状态与既有 UTF-16 选区规则，不把只读 `ArticleBody` 简单改为无约束的 `contentEditable`。

必须验证日语／中文输入法合成、重复词定位、跨句与跨段选区、注音词完整性、撤销／重做和取消。合成输入过程中不得因重新渲染而丢字、跳光标或破坏选区。

## 执行顺序与验收

| 顺序 | 工作 | 验收重点 |
| --- | --- | --- |
| 1 | PWA 选择与登录会话同步 | 同会话刷新／重开／重复事件不再提示；退出与过期行为一致；iOS、原生弹窗拒绝、已安装状态覆盖 |
| 2 | 对话按钮精简与 Markdown | 冗余按钮消失；旧／新回复正确渲染；来源可点；HTML 与危险链接不会执行 |
| 3 | 关联历史与穿插时间线 | A／B／A 场景筛选正确，多组交叠和继续追问归属正确，可返回全部，不增加模型请求 |
| 4 | 阅读与实际编辑面的高亮、布局 | 整句含注音与多来源时准确；标记可点；编辑区域够用；无重复结构预览；IME 与既有校对流程正常 |
| 5 | 回归与视觉检查 | 桌面／手机、长文本、长回答、代码／表格、选择与编辑均无溢出或状态丢失 |

执行时运行 `npm run check`、阅读／校对浏览器回归和账号／AI 浏览器回归；涉及生产构建的命令依次运行，避免并发改写 `dist`。补充针对会话 Cookie、Markdown、交错组历史、真实编辑面高亮与输入法的有效回归，并人工核对淡色高亮和编辑空间。

沿用已确认约束：不恢复本地 OCR 专属测试；树莓派部署默认不跑完整测试，需显式 `--test`。本子计划先实现并完成本机验证，后续提交、推送和部署按开始执行时的指令办理。


## 执行记录（2026-10-30）

- PWA 选择保存到 Cookie，使用服务端返回的真实网站会话期限；认证 Cookie 仍为 HttpOnly。覆盖访客承接登录、退出、过期、切换账号、原生安装结果、旧 iOS 关闭记录与无 Cookie 回退，证书入口独立保留。
- AI 回复采用 `react-markdown` 与 `remark-gfm`，禁用原始 HTML 并限制链接协议；用户问题保持原始文本，表格和代码块局部滚动。对话面板的重复翻译／语法按钮已删除。
- 关联历史按保存序列筛选，保留 A／B／A 穿插顺序；筛选范围与追问目标分离。等待回复时切换片段，迟到的回复不会覆盖新的筛选和追问目标；打开历史不会发起模型请求。
- 阅读高亮按实际文字、注音位置绘制，约 120 毫秒背景渐变；支持系统减少动画设置。修复注音展示切片丢失句子、来源和问答标记的问题，整句跨来源和振假名时仍整体响应。
- 桌面预留右侧记录区并固定面板，手机采用底部覆盖式抽屉；消息单独滚动，打开、切换和关闭记录不改变正文位置。
- 编辑面保留原生 textarea，采用同步装饰层；已实测换行、滚动、字号变化及中日文合成输入。独立记录入口位于实际输入框工具行，普通点击、双击及拖动继续用于编辑。无原图时正文单列扩宽，有原图时保留对照；重复结构折叠区已删除。
- 编辑器中的新问答及删除结果同步至阅读状态，取消后无需刷新即可看到真实标记。删除组会从当前正文和所有撤销／重做快照清理。新组仅回填正文完全相同的快照；不同正文的历史快照保留原有精确关联，不猜测重复词位置，没有可靠锚点的新组按游离规则处理。

## 后续图片工作流与发布验收（2026-10-30）

- 文章图片与对应正文成对保存，上传与校对页统一使用当前照片的“前移／后移”按钮调整顺序；手机保留紧凑缩略图。
- 多图导入先选书籍、再选文章；队列状态和移除叉号集中在缩略图区域，当前照片信息位于预览上方。识别与注音结果按图片分别缓存，失败重试保留已完成步骤。
- 识别前可逐张左右旋转，预览完整适配方向；上传后实际保存旋转后的图片像素，再执行 OCR 和注音。修改方向使旧识别缓存失效；旋转回复不确定时从本地原图重新上传，避免重复叠加方向。
- 校对正文只显示当前照片文字，注音操作位于独立标签页；记录入口预留空间，显示时不挤动正文。
- 校对页支持移除图片及对应正文，至少保留一张图片；支持撤销／重做及取消，保存后才解除文章关联。其余图片、注音、讨论历史和原图文件保留。
- 保存后分句在后台进行，“添加图片文章”和“继续添加图片”可继续使用。
- 最新单元／接口测试 250 项通过；发布前浏览器回归共 108 项通过，包括编辑／图片 74 项、聊天／阅读 4 项及常规／PWA 30 项，覆盖桌面及手机。已通过 GUI 验证按钮排序、识别前旋转、真实图片方向、图文移除、撤销／重做及保存重开；GUI 使用隔离数据和模拟 AI 结果。
