# 第一阶段：阅读、保存与注音校对

日期：2026-10-28。当前交付用于本机验收，后续阶段等待用户反馈后展开。

## 打开页面

构建后 `npm start`，访问 <http://127.0.0.1:4317>。

首次书架为空。首页的排版参考及「试试注音示例」来自用户提供的两张歌词样本，明确标为示例，不代表 OCR 或 AI 的识别结果。只有点击保存后，示例才会进入书架。

## 建议验收顺序

1. 点击「试试注音示例」。检查右侧阅读预览：口（くち）、開（あ）、言葉（ことば）、歯石（しせき）、背中（せなか）按日式 ruby 显示；生まれた只给「生」标「う」。送假名保留在正文里，歌词空行保留。
2. 在「注音校正」中修改一个读音，确认预览同步变化。也可以回到「正文编辑」，选中一个同一行的字词，在下方输入假名并点「添加注音」。修改词组读音时可选中完整词组，或在注音列表中修改。
3. 保存并阅读，试试隐藏／显示注音和调节字号。刷新后从书架重新打开，确认内容仍在。
4. 导入你自己的文字并保存，用书架搜索标题或正文；尝试 Markdown、JSON 导出。
5. 改变窗口宽度到手机尺寸：书架收入左上角菜单，编辑和预览上下排列。也欢迎反馈字号、留白、字体和校对操作是否顺手。

## 已实现

- 文字／歌词导入、类型、标题与横／竖阅读方向。
- 按词或词组添加、修改、移除注音，预览同步更新。
- 原文编辑不会把读音混入正文；不能可靠对应的注音会移除并显示提示，不盲目转移到相邻重复字词。
- SQLite 持久保存、重开、搜索、删除及 Markdown / JSON 导出。
- 未保存离开提醒；保存期间锁定编辑；更新和删除均检查版本，防止旧页面覆盖新版本。
- 本机地址访问限制，拒绝外部 Host 和跨站写入。尚未接入账户，当前只绑定本机地址。
