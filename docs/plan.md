## 第一阶段：可用的阅读与校对基础（当前）

实现：文字／歌词导入、书架、重开阅读、保留分行、日式振假名、修改正文与读音、注音显示开关、字号调节、JSON / Markdown 导出。个人本机使用、SQLite 持久保存，不开放远程访问。

验收：

- [ ] 用用户提供的格式示例确认注音位置、词组对应和送假名。
- [ ] 粘贴新材料、保存、刷新重开，正文、分行、读音不丢失。
- [ ] 能通过编辑界面修正词组读音，保存结果一致。
- [ ] 桌面与手机尺寸可读可编辑。
- [ ] 服务重启后数据仍在，导出内容正确。
- [ ] 测试通过并提交 Git，交给用户验收后再开展第二阶段。

并行调查：仅核实官方订阅接入说明、CLI 与认证状态，不擅自调用付费 API 或读取登录 token；真实 AI 能力在下一阶段验证。

## 第二阶段：真实 AI 与图片导入

先完成官方订阅授权及真实推理验证，再接入界面。验证图片输入、结构化 OCR、原有振假名、批注分离和竖排双页顺序。原图保留，识别先生成可修改的草稿，不直接替换已校对原文。

验收：三张真实样本＋新的非固定输入；中文解释、多轮追问、重启续聊；明确认证路径与用量限制。任何费用／能力取舍带具体结果确认。

## 第三阶段：旁注、笔记本与账户

选区附近问 AI、多轮对话转旁注、手写笔记、共享同一笔记数据的笔记本、标签搜索、来源回跳。编辑原文时校验锚点，不能匹配就提示重新指定。接入私用账户和资料隔离，为少量朋友准备各自授权。

验收：完整阅读→提问→追问→笔记→修改→回原文流程，聊天不丢失，多账户数据不能交叉访问。

## 第四阶段：朗读、复习与备份

真实材料验证免费的日语语音路线；全文／单句／选区朗读、暂停／重复／慢速、当前句提示，使用校正读音。自选笔记加入复习，反馈安排下次复习。补齐备份与恢复。

验收：实际可播放并听评；复习保留语境；备份可恢复。未验证的声音质量如实标记。
