## 当前约定与边界

- 任务不允许手动暂停；只有出错暂停的任务可删除。识别／注音失败保留原图和成功结果，支持人工处理。
- 自动处理需完成识别、注音和整批分句，才算执行完成；失败仍可人工校对兜底。用户手动保存或追加后才写入文章并归档。
- 已上传内容与后台结果可跨设备恢复；尚未上传完的本地文件需重新选择，未保存的人工校对不提供自动跨设备恢复。
- 当前使用共享 ChatGPT 授权和单服务 SQLite；其他 AI 提供方仅预留，本地 OCR 仅供实验对照。离线提交、通知推送和多实例调度尚未纳入计划。
- 当前统一横排阅读，提取正文与读音，不自动拆双页、还原原版布局或整理手写批注。

## 后续开发

### 当前迭代：阅读布局与移动端 AI 对话

用户已于 2026-10-31 确认纯 UI demo 及三个入口方案，正式界面已按确认版本实现，尚未部署。

- [x] 桌面侧栏可完全隐藏并记住本设备选择，手机书架独立控制；对话关闭后回收右侧占位，阅读容器左右约 24px、上限约 960px，开合时尽量保持当前阅读段落位置。
- [x] 手机对话占可见屏幕约 92%；顶部合并标题、片段／全部切换及“更多”，文章信息和删除操作收入“更多”，引用和来源默认折叠。单组隐藏追问目标，多组使用紧凑入口；输入与发送同排、最多自动增高至四行，等待回答只用一行提示。
- [x] 顶部把手或标题空白区域下拉超过 80px 收起，底部把手上划超过 80px 恢复，短拖回弹；普通阅读／消息滚动不触发开合，避开系统底部手势区，保留箭头与把手的点击和键盘操作，不再提供“继续对话”按钮。
- [x] 三个入口：①上划恢复该篇上次的筛选范围、追问目标、草稿、消息滚动位置及引用展开状态；②点击已有问答词语进入对应讨论并继续追问；③新选中文字发起问题。没有上次状态时显示该篇记录或空态，不自动提问。
- [x] 收起只隐藏对话，不中断正在生成的回答；收起期间收到结果也不把恢复位置推到末尾。恢复不自动聚焦输入框或唤起键盘，关闭后恢复原文滚动位置；面板适配可见视口、安全区和键盘高度。
- [x] 草稿按文章和问答组隔离，阅读页和校对页共享本次页面会话状态，刷新后清除。成功发送／删除后清除对应草稿，发送失败保留；新问题尚未建立问答组就失败时，保留选区和问题并支持重试。服务端 API、数据库及问答原始顺序不变。

自动化验收覆盖桌面 1024／1100／1440px 与手机 320–430px、浏览器触摸事件模拟、上下划及短拖回弹、长对话原位恢复、收起期间返回回答、分组与跨页面草稿、失败重试、删除清理及刷新清除。390×844 默认消息区至少占面板高度的 65%，并模拟可见视口缩小和偏移检查输入／发送无遮挡。单元／接口测试、相关浏览器回归及构建已通过；实际设备软键盘与安全区体验仍按上方「待体验验收」继续核对。
