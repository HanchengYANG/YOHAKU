# 余白：分阶段实施与验收

更新日期：2026-10-28。

## 已确认的范围

- 先供本人使用，后续最多一两位朋友，资料与对话按账户隔离。
- 当前只在本机实现。树莓派部署放到本机主流程验收之后；公网入口、穿透、VPN 由用户负责。
- 优先歌词、横排文章和教材，兼顾竖排书籍输入；新输出统一横排阅读，原图方向保留为来源信息。
- 截图与照片是主要输入，导入 → 识别 → 对照校对 → 保存应顺畅；支持直接粘贴截图、选图和拖放。便捷输入的新增操作需单独验证，不能因已有选图流程通过就标记全部完成。
- 振假名采用日式ruby。存储与校对保留完整词或实际词形，例如食べる→たべる、生まれた→うまれた、背中→せなか；阅读时仅汉字部分显示小假名，正文里的假名不重复标注。例如お父さん只在父上显示とう，食べる只在食上显示た，校对条目仍是整词。
- 用户澄清：忽略原图注音只适用于小字读不清的情况。清晰可辨的原图读音优先采用并标source；缺失或模糊才由AI按上下文补充并标generated，不能以词典常见读法替换清晰的特殊注音。无可靠依据时留空或提示。无原图依据的名字可按语境读ミンツー或みょうじ，不做全局同词统一。新识别不重复给纯假名注音；历史source、generated和manual读音记录不自动迁移。
- 人工注音支持范围控制：按词查找所有出现位置，可全选或只勾选部分位置批量应用读音。例如可把全篇名字改为みょうじ，也可将一部分设为みょうじ、另一部分设为ミンツー。人工明确全选时允许全文修改；没有人工操作时，AI不擅自将同词全部统一。此功能已完成开发自检，用户体验验收仍待反馈。
- 用户本轮补充：注音校对项聚焦时，原文中对应出现位置高亮；批量查找在全文中直接点选范围。照片旋转后可保存，更新应用内同一图片的当前像素方向，重开无需再次旋转。
- AI只调整格式排版，逐字保留原文用词、标点和专名，不润色、不纠错品牌拼写、不翻译补写。允许合并物理折行、段落分组，将已有标题、角色名及说明组织成层次；不新增原图没有的标题或解释正文。
- 不创建 API key、不使用额外收费模型 API；验证官方 Codex / Sign in with ChatGPT 订阅授权路径。
- 每阶段提供可操作的验收结果；用户验收后再展开下一阶段。源码、文档、样本、本地数据分类，合适节点提交 Git。
- 用户补充：网站账号必须与各自 AI 授权配对，不能共享管理员额度。AI provider 必须抽象；目前仅实现 OpenAI，Claude 与 API Base 只留空预留。
